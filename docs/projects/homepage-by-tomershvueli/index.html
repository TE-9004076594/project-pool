项目简介

This project is a simple, standalone, self-hosted PHP page that is meant to be your window to your server and the web. It is your minimalist corner of the internet. The background will update with a gorgeous (and royalty free) image from [Unsplash](https://unsplash.com/), or a custom source every 20 seconds. With it, a simple menu is available to you with your most frequented links. All the assets needed are part of the repo so it can run offline (though it won't fetch pretty background...
