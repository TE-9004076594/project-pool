项目简介

Mikochi is a remote file browser for your self-hosted server or NAS. It allows you to browse remote folders, upload, delete, rename and download files. You can also use it to generate streaming links which can be played using VLC or mpv * Browse files on you remote server * Fuzzy search * Upload new files and create folders * Rename and delete files * Download...
