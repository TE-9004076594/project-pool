项目简介

So you run a bunch of self-hosted services for multiple users but are tired of handing out links? No problem, Hubleys got you covered. - separate dashboard per user, according to their groups/permissions - all dashboard contents are predefined by the admin(s) - dashboard features: - link tiles, organized by folders - search engines with autocomplete - upcoming calendar events - show messages to the users - customizable & dynamic backgrounds - current weather & forecast - clock, stopwatch,...
